# Group chat: Daily desk

Create after Chief of Staff, GTM, and Product exist.

## How

New group chat → add **Chief of Staff**, **GTM**, **Product** (add **Ops** when it exists). Pin it. This is the only chat you should need most mornings.

### First message in the group

```
You three (four if Ops is here) are the Touch2Sign desk.

Chief of Staff chairs. Each weekday after the 08:00 brief, CoS posts in THIS chat a 8–12 line desk note:
1. What needs Robert today (named)
2. GTM: replies / drafts waiting / do-not-send count
3. Product: PRs / CI / blockers
4. Ops: down or money (or “quiet”)
5. One question max if something is ambiguous

Rules:
- Do not @ Robert for FYI. @ him only when a decision or approval is required (send, merge, pay).
- Do not duplicate long reports that already live in your private chats.
- If you need another specialist bot, propose it here — do not create it.

Today: each of you post a 5-line “I am alive and connected to: …” so we can see broken plugins immediately.
```

## What you do

Read **Daily desk** on the phone. Approve sends in the GTM chat (`send 1,2`). Approve merges on GitHub yourself. Do not let the group become a fourth inbox of drafts.
